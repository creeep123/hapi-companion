# HAPI Companion v0.1.0

HAPI Companion v0.1.0 is a source-first developer release for self-hosted HAPI users on macOS 14 or newer.

## What is ready

- native banner, audible completion cue, durable delivery, and exact-session navigation;
- same-window targeting for an installed Microsoft Edge HAPI PWA;
- reproducible XcodeGen project and local installer;
- reviewed HAPI 0.29.0 Hub integration patch;
- complete Signal Buddy brand assets.

## Recommended installation

Ask a local coding agent to clone the repository, read `AGENTS.md` and `README.md`, run `scripts/doctor.sh`, and then run `install-local.sh`. Building locally avoids asking users to trust an unnotarized downloaded application.

## Release assets

- `HAPI-Companion-v0.1.0-macOS-ad-hoc.zip`: universal development build. It is ad-hoc signed and **not notarized**; source installation is preferred.
- `HAPI-Companion-v0.1.0-brand-assets.zip`: approved Signal Buddy masters, exports, tokens, manifest, and checksums.
- `HAPI-Companion-v0.1.0-HAPI-0.29.0.patch`: Hub transport integration tied to the documented baseline.
- `SHA256SUMS.txt`: integrity hashes for all release assets.

## Compatibility and limitations

- macOS 14+; tested locally on Apple Silicon and compiled as a universal app.
- exact existing-window automation supports Microsoft Edge PWA installations.
- Hub patch baseline: `tiann/hapi@d3d4fd1706564782e9a58b917df4e0677f65051f`.
- Developer ID signing and Apple notarization are not included in v0.1.0.
- This is an independent community project, not an official HAPI release.

## Upgrade and rollback

The local installer replaces `~/Applications/HAPI Companion.app` only after a successful build and re-pairs the device-scoped credential. To roll back the app, reinstall the previous known-good bundle/source commit. Hub rollback requires the previously recorded Hub artifact and, after schema migration, the corresponding database backup.
