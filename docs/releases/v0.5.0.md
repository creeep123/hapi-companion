# HAPI Companion v0.5.0

Release status: candidate validation.

- Adds “像素金币 · 清脆” and “像素金币 · 双音” as calibrated bundled notification sounds.
- Prevents a notification click from briefly opening the Companion settings window.
- Sends the exact session to Edge in one operation; the matching HAPI web patch uses PWA Launch Handler and client-side routing to avoid a full reload when supported.

The Hub API, database schema, durable SSE/ACK transport and Mobile Relay contract are unchanged. The cumulative HAPI patch hash changes because the embedded PWA launch behavior changes; automatic Hub upgrades require a matching updater pin and fresh gate acceptance before production deployment.
