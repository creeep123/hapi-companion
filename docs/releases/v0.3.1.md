# HAPI Companion v0.3.1

Adds free application updates using Sparkle 2.9.6 and public GitHub release archives and a signed feed on the free jsDelivr GitHub CDN.

- “声音与设置” shows version/build, “检查更新…” and optional daily automatic checks.
- Background discovery posts a silent new-version notification and shows an update entry in settings. Click to review and install; Sparkle downloads, verifies, replaces and relaunches the app.
- No automatic installation, account, subscription, payment or Hub/updater deployment.
- Signed feed and signed archives are verified before extraction. Reminder rules, imported sounds and selected Hub configuration remain outside the replaced bundle.

Older v0.2.2 clients require one manual installation of this version. Current distribution remains ad-hoc signed and is not Apple-notarized. Internet access to jsDelivr and GitHub API/download storage is required; a network error leaves the installed version in place.

Release/runtime acceptance evidence is maintained in docs/deployments. v0.3.0 remains an unrecommended prerelease used to detect a native-network routing problem; this release uses the verified public API routes.
