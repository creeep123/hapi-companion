# HAPI Companion v0.5.1

This hotfix prevents a Debug, copied or older HAPI Companion app from running alongside the installed login-item app and creating a second menu-bar icon. The first process holds a macOS user-scoped lifetime lock; later copies exit before connecting to HAPI or creating UI.

It retains the v0.5.0 pixel coin sounds and smooth PWA launch changes. The Hub patch, updater pin, Mobile Relay and stored user settings are unchanged.
