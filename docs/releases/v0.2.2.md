# HAPI Companion v0.2.2

User accepted the sound controls and settings layout and authorized release on 2026-09-10. This is the normal Companion application, not the isolated preview.

## Changes since v0.1.0

- Two settings tabs: reminder rules first; system settings and sounds on the secondary page.
- Select real conversations or title keywords, skip short turns and configure quiet hours.
- Original completion timbre plus five AOSP phone notification cues, calibrated to -23 LUFS, with app-only 0–100% volume and custom audio import.
- Persist an independent HAPI configuration directory so multiple Runners can coexist without changing their settings.

## Installation and update

Download `HAPI-Companion-v0.2.2-macOS-ad-hoc.zip` and `SHA256SUMS.txt` from this release. The archive contains a universal arm64/x86_64 app for macOS 14+. It is ad-hoc signed, not Developer ID signed or Apple-notarized. Full Xcode is required only for source builds.

Follow [updating an existing Mac](../agents/UPDATE_MAC.md). Back up the old app outside Applications, verify the checksum/signature, quit Companion and replace its bundle cleanly. Preferences, imported audio and Runner settings stay outside the app and must not be removed. An ad-hoc update may require re-pairing its app-scoped device credential.

There is no in-app update checker, new-version reminder or one-click update in v0.2.2. A future Sparkle integration would require a one-time manual upgrade to a version containing it. HAPI Safe Updater manages the server, not the Mac application.
