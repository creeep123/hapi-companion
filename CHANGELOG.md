# Changelog

All notable changes are documented here.

## 0.1.0 — 2026-09-05

Initial public source release.

- native macOS banner and bundled completion sound;
- device-scoped pairing through existing HAPI CLI configuration;
- durable SSE delivery, explicit ACK, replay, and local deduplication;
- exact-session click-through with existing Edge HAPI PWA reuse;
- dynamic Hub and PWA discovery with no personal deployment identifiers;
- Signal Buddy visual identity, app icon, menu-bar template icon, SVG masters, tokens, and asset manifest;
- Agent-first doctor, local installer, test commands, Control Panel, and HAPI 0.29.0 integration patch.
