# Signal Buddy generation notes

The first representative raster concept was generated with OpenAI's built-in image generation tool on 2026-09-05. It used the existing AGPL HAPI icon as a family-equity reference and the publicly visible Vibe Island icon only as a simplicity/character reference. The prompt explicitly prohibited copying either mark.

The approved production mark was then reconstructed as original editable SVG geometry in this repository. Production assets must be generated from the SVG masters with `scripts/generate-brand-assets.sh`; the concept PNG is not a production master.

Core prompt intent: “a compact friendly coral companion shaped like a tiny desktop pager/bell, dark aubergine notification screen, minimal warm-white eyes, mint completion sparkle, single bell clapper, vector-friendly, no text, no Wi-Fi arcs, no copied device casing or pixel face.”
